### Для production деплоя на Timeweb нужно:

1. **Загрузить папку `api/` на хостинг** (50 KB)
2. **Установить права доступа:**
   ```bash
   chmod 777 api/
   chmod 666 api/database.sqlite
   ```
3. **Настроить переменную окружения:**
   ```bash
   JWT_SECRET="your-production-secret-key"
   ```
4. **Готово!** Сайт работает.

## 📁 Структура для деплоя

На хостинг загружается только папка `api/`:
```
api/
├── index.php          # Главный файл (1328 строк)
├── database.php       # Схема БД (160 строк)
├── auth.php           # JWT авторизация (137 строк)
├── router.php         # HTTP роутер (91 строка)
├── config.php         # Конфигурация (28 строк)
├── catalog.php        # Статические данные (64 строки)
├── forum.php          # Forum helpers (222 строки)
├── seed.php           # Демо-данные (57 строк)
├── .htaccess          # Apache rewrite rules
└── database.sqlite    # База данных (создается автоматически)
```

## 💎 Ключевые преимущества новой архитектуры

1. **Независимость** — не требует Node.js, PostgreSQL, внешних сервисов
2. **Простота деплоя** — один хостинг для всего (Timeweb ready)
3. **Портативность** — вся БД в одном файле (легко бэкапить)
4. **Производительность** — SQLite быстрее для малых нагрузок
5. **Совместимость** — работает на любом PHP хостинге с Apache
6. **Безопасность** — PDO prepared statements, JWT в HTTP-only cookies
7. **Масштабируемость** — легко мигрировать на MySQL/PostgreSQL при росте
