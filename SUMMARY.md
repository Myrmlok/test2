#### 📝 Что нужно для production

1. **Настройка Vite proxy** (5 минут)
   - Добавить в `artifacts/4bor-club/vite.config.ts`:
   ```typescript
   server: {
     proxy: {
       '/api': 'http://localhost:8000'
     }
   }
   ```

2. **Установить JWT_SECRET** (1 минута)
   ```bash
   export JWT_SECRET="your-production-secret-key"
   ```

3. **Деплой на Timeweb** (10 минут)
   - Загрузить папку `api/` на хостинг
   - Проверить права: `chmod 777 api/ && chmod 666 api/database.sqlite`
   - Готово!
